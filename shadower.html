KMS 1.2.419 패치 반영

섀도어

변경 항목 24개 · 툴팁 43장 · 테스트월드와 다른 항목 9개

왼쪽 · 변경 전→오른쪽 · 바뀐 내용툴팁 이미지는 왼쪽이 변경 전, 오른쪽이 바뀐 내용입니다.

모험가 공통

에픽 어드벤쳐

  • 모험가 직업군 파티원의 데미지를 증가시키는 기능이 삭제됩니다.

섀도어

플래시 점프 본섭 변경

  • 전방으로 사용 시 일부 스킬을 제외한 다른 스킬 사용 중 사용할 수 있게 변경됩니다.
  • 전방으로 점프 후 위 방향으로 점프할 수 있게 변경됩니다.
  • 위 방향으로 점프한 후 전방으로 점프할 수 있게 변경됩니다.

무스펠 하임

  • 마스터 레벨이 20에서 10으로 변경됩니다.
  • 시전 동작이 삭제됩니다.
  • 키다운 스킬을 제외한 다른 스킬 사용 중 사용할 수 있게 변경됩니다.
  • 스킬 아이콘 및 스킬 이펙트가 변경됩니다.
  • 시전 효과음이 변경됩니다.
  • 공격 기능이 삭제됩니다.
  • 적을 밀어내는 기능이 삭제됩니다.
  • 이동 거리가 변경됩니다.
  • 연속 사용 가능한 딜레이가 약 6% 감소됩니다.
  • 공격력이 영구적으로 증가하는 기능이 추가됩니다.
  • 스킬 매크로에 등록할 수 없게 변경됩니다.

메소 익스플로젼

  • 동전 1개당 데미지가 마스터 레벨 기준 100%에서 85%로 감소됩니다.

다크 플레어

  • 스킬 설명이 변경됩니다.
  • 사냥 맵을 제외한 일부 맵에서 사용할 수 없게 됩니다.

픽 파킷

  • 가끔 공격한 적과 다른 위치에서 동전이 떨어지는 현상이 수정됩니다.

메소 가드 본섭 변경

  • 신규 스킬이 추가됩니다.
  • 메소를 이용해 적의 공격을 막아내는 스킬입니다.

크루얼 스탭

  • 최종 데미지 증가량이 마스터 레벨 기준 24%에서 22%로 감소됩니다.

블러디 파킷

  • 가끔 공격한 적과 다른 위치에서 동전이 떨어지는 현상이 수정됩니다.
  • 크리티컬 데미지 증가량이 마스터 레벨 기준 20%에서 15%로 감소됩니다.

써든레이드

  • 데미지가 마스터 레벨 기준 494%에서 195%로 감소됩니다.
  • 적중한 적에게 도트 데미지가 적용되는 기능이 삭제됩니다.
  • 일반 몬스터 공격 시 데미지가 증가하는 기능이 추가됩니다.

연막탄 본섭 변경

  • 파티원에게 연막탄 내부의 적이 받는 크리티컬 데미지 증가 효과를 적용하는 기능이 삭제됩니다.
  • 스킬 사용 시 캐릭터 위치에 설치되도록 변경됩니다.
  • 재사용 대기시간 초기화 효과를 받지 않도록 변경됩니다.
  • 아래 방향키와 함께 스킬을 재사용 시 연막탄을 재소환하는 기능이 스킬 재사용 시 연막탄을 재소환하는 기능으로 변경됩니다.

베일 오브 섀도우 본섭 변경

  • 스킬 설명이 변경됩니다.
  • 스킬 사용 시 다크 사이트가 적용되는 기능이 추가됩니다.
  • 스킬 재사용 시 협력자를 재소환하는 기능이 추가됩니다.
  • 사망 후 부활 시에도 협력자의 공격이 유지되도록 변경됩니다.

살생유택 본섭 변경

  • 신규 스킬이 추가됩니다.
  • 살의의 대상을 고르는 스킬입니다.

절개 본섭 변경

  • 신규 모드인 절개 : 멸이 추가됩니다.
  • 상처의 지속 시간 제한이 삭제됩니다.
  • 상처 디버프가 최대 1회까지 중첩되도록 변경됩니다.
  • 상처 디버프의 지속 시간 제한이 삭제됩니다.
  • 암살이나 소닉 블로우 사용 중 절개 : 멸로 연계하여도 상처 디버프를 소모하지 않도록 변경됩니다.
  • 암살이나 소닉 블로우 사용 중 절개 : 멸로 연계 시 상처 디버프가 적용된 적의 위치로 이동하도록 변경됩니다.

소닉 블로우 본섭 변경

  • 스킬 사용 중 방향 전환을 할 수 있는 기능이 추가됩니다.
  • 스킬 사용 중 이동 및 점프를 할 수 있게 변경됩니다.
  • 스킬을 재사용하여 스킬 사용을 취소할 수 있는 기능이 추가됩니다.
  • 공격 지속 시간이 2초에서 1.8초로 감소됩니다.
  • 공격을 중단했을 때 남은 공격 횟수 1회당 재사용 대기시간 감소량이 3.3초에서 4.5초로 증가됩니다.
  • 연속 공격의 데미지가 마스터 레벨 기준 1470%에서 2103%로 증가됩니다.

메소 익스플로젼 VI

  • 동전 1개 당 데미지가 마스터 레벨 기준 300%에서 276%로 감소됩니다.

다크 플레어 VI

  • 사냥 맵을 제외한 일부 맵에서 사용할 수 없게 됩니다.
  • 공격력이 영구적으로 증가하는 기능이 추가됩니다.

써든레이드 VI

  • 데미지가 마스터 레벨 기준 800%에서 300%로 감소됩니다.
  • 적중한 적에게 도트 데미지가 적용되는 기능이 삭제됩니다.
  • 일반 몬스터 공격 시 데미지가 증가하는 기능이 추가됩니다.

베일 오브 섀도우 VI 본섭 변경

  • 스킬 설명이 변경됩니다.
  • 스킬 사용 시 다크 사이트가 적용되는 기능이 추가됩니다.
  • 스킬 재사용 시 협력자를 재소환하는 기능이 추가됩니다.
  • 사망 후 부활 시에도 협력자의 공격이 유지되도록 변경됩니다.

커버트 쉐도우

  • 다크 사이트를 일정 시간 이상 유지할 경우 쉐도우 엣지로 강화되는 기능이 삭제됩니다.
  • 연막탄이나 베일 오브 섀도우 사용 시 쉐도우 엣지로 강화되는 기능이 추가됩니다.
  • 쉐도우 엣지의 지속 시간이 3초에서 15초로 증가됩니다.
  • 연막탄으로 강화된 쉐도우 엣지 적용 중 베일 오브 섀도우를 사용하거나, 베일 오브 섀도우로 강화된 쉐도우 엣지 사용 중 연막탄 사용 시 1회에 한하여 쉐도우 엣지의 지속 시간이 15초 증가하는 기능이 추가됩니다.
  • 치명적인 일격의 데미지가 마스터 레벨 기준 160%에서 137%로 감소됩니다.

일도양단

  • 첫 번째 참격의 데미지가 마스터 레벨 기준 960%에서 1152%로 증가됩니다.
  • 두 번째 참격의 데미지가 마스터 레벨 기준 782%에서 938%로 증가됩니다.
  • 마무리 일격의 데미지가 마스터 레벨 기준 850%에서 1020%로 증가됩니다.

어센틱 다크니스

  • 참격의 데미지가 마스터 레벨 기준 5016%에서 4966%로 감소됩니다.

무아지경 본섭 변경

  • 암살 : 멸의 참격의 데미지가 마스터 레벨 기준 400%에서 571%로 증가됩니다.
  • 분쇄 : 멸의 난격의 데미지가 마스터 레벨 기준 388%에서 553%로 증가됩니다.
  • 분쇄 : 멸의 검영의 데미지가 마스터 레벨 기준 567%에서 809%로 증가됩니다.
  • 암살 : 멸과 분쇄 : 멸을 엎드린 채로 사용할 수 있는 현상이 수정됩니다.
  • 직접 공격하는 스킬 적중 시 메소 익스플로젼이 자동 발동되는 기능이 일정 시간마다 메소 익스플로젼이 자동 발동되는 기능으로 변경됩니다.

솔 헤카테

  • 솔 에르다 입자의 데미지가 마스터 레벨 기준 798%에서 848%로 증가됩니다.

V 코어 변경점

  • 무스펠 하임 강화 코어가 새비지 블로우 강화 코어로 변경됩니다.
  • 엣지 카니발/새비지 블로우 강화 코어가 엣지 카니발 강화 코어로 변경됩니다.

HEXA 코어 변경점

  • 절개 강화 코어 활성화 시 효과가 절개/절개 : 멸의 최종 데미지 증가로 변경됩니다.

기타 툴팁 변경

공지 본문에 스킬 이름이 직접 나오지는 않지만 툴팁이 바뀐 스킬입니다.
