KMS 1.2.419 패치 반영

마족

레테

변경 항목 11개 · 툴팁 14장 · 테스트월드와 다른 항목 4개

마족 공통레테
왼쪽 · 변경 전→오른쪽 · 바뀐 내용툴팁 이미지는 왼쪽이 변경 전, 오른쪽이 바뀐 내용입니다.

마족 공통

마스테리안 그릿

  • 마족 직업군 파티원의 데미지를 증가시키는 기능이 삭제됩니다.

레테

인보크 : 템플러

  • 일부 맵에서 템플러가 어색하게 동작하는 현상이 수정됩니다.

오블리크 텔레포트

  • 텔레포트로 발동 잠금 기능이 추가됩니다. 텔레포트로 발동 잠금 시 오블리크 텔레포트를 별도 키세팅으로 사용할 수 있게 됩니다.

오버로드 : 템플러 온슬로트

  • 데미지가 마스터 레벨 기준 900%에서 990%로 증가됩니다.

오버로드 : 바르가르 트라이던트

  • 데미지가 마스터 레벨 기준 1500%에서 1650%로 증가됩니다.

이딕트 : 펠 스톰 VI 본섭 변경

  • 데미지가 마스터 레벨 기준 712%에서 715%로 증가됩니다.

이딕트 : 램페이지 VI 본섭 변경

  • 데미지가 마스터 레벨 기준 760%에서 833%로 증가됩니다.

이딕트 : 템플러 아츠 VI 본섭 변경

  • 데미지가 마스터 레벨 기준 764%에서 838%로 증가됩니다.

팩트 매니페스트

  • 데미지가 마스터 레벨 기준 184%에서 221%로 증가됩니다.

앱솔루트 레인

  • 마력 사슬의 데미지가 마스터 레벨 기준 4340%에서 4377%로 증가됩니다.
  • 아난케의 포용의 데미지가 마스터 레벨 기준 4760%에서 4800%로 증가됩니다.

솔 헤카테 본섭 추가

  • 솔 에르다 입자의 데미지가 마스터 레벨 기준 677%에서 725%로 증가됩니다.
