KMS 1.2.419 패치 반영

레프

칼리

변경 항목 21개 · 툴팁 18장 · 테스트월드와 다른 항목 5개

레프 공통칼리움짤
왼쪽 · 변경 전→오른쪽 · 바뀐 내용툴팁 이미지는 왼쪽이 변경 전, 오른쪽이 바뀐 내용입니다.

레프 공통

레이스 오브 갓

  • 레프 직업군 파티원의 데미지를 증가시키는 기능이 삭제됩니다.

칼리

스파크

  • 스킬 설명이 변경됩니다.
  • 전방으로 사용 시 일부 스킬을 제외한 다른 스킬 사용 중 사용할 수 있게 변경됩니다.
  • 전방으로 1회 점프 후 위 방향으로 점프할 수 있게 변경됩니다.
  • 위 방향으로 점프한 후 전방으로 1회 점프할 수 있게 변경됩니다.

임펄스

  • 마스터 레벨이 9에서 8로 변경됩니다.
  • 크리티컬 확률 공식이 변경됩니다.
  • 크리티컬 데미지 공식이 변경됩니다.

미라지 스텝 본섭 변경

  • 신규 스킬이 추가됩니다.
  • 일정 거리만큼 순간 이동하는 스킬입니다.

레조네이트 본섭 변경

  • 범위 내 대상이 없을 경우 유지 시간이 25% 증가됩니다.

보이드 러쉬

  • 일루전 링 : 거대한 몸 장착 후 스킬 사용 시 성능이 저하되는 현상이 수정됩니다.
  • 일루전 링 : 거대한 머리 장착 후 스킬 사용 시 잔상에 얼굴이 보이지 않는 현상이 수정됩니다.

보이드 블리츠

  • 일루전 링 : 거대한 몸 장착 후 스킬 사용 시 성능이 저하되는 현상이 수정됩니다.
  • 일루전 링 : 거대한 머리 장착 후 스킬 사용 시 잔상에 얼굴이 보이지 않는 현상이 수정됩니다.

헥스 : 차크람 퓨리

  • 데미지가 마스터 레벨 기준 735%에서 710%로 감소됩니다.

차크람 엑스퍼트

  • 크리티컬 데미지 증가량이 마스터 레벨 기준 23%에서 17%로 감소됩니다.

리뎀션

  • 최종 데미지 증가량이 마스터 레벨 기준 35%에서 32%로 감소됩니다.

아츠 : 아스트라

  • 데미지가 마스터 레벨 기준 1100%에서 1045%로 감소됩니다.
  • 소멸 데미지가 마스터 레벨 기준 1210%에서 1150%로 감소됩니다.

레조네이트 : 얼티메이텀 본섭 변경

  • 범위 내 대상이 없을 경우 각성 레조네이트의 유지 시간이 25% 증가됩니다.

헥스 : 판데모니움 본섭 변경

  • 시전 이펙트가 변경됩니다.
  • 시전 효과음이 변경됩니다.
  • 공격 시간이 약 3초에서 약 2초로 감소됩니다.

보이드 버스트

  • 버프 아이콘에 마우스 오버 시 스킬 설명이 출력되지 않는 현상이 수정됩니다.

헥스 : 차크람 퓨리 VI

  • 질주 데미지가 마스터 레벨 기준 1435%에서 1322%로 감소됩니다.

보이드 러쉬 VI

  • 일루전 링 : 거대한 몸 장착 후 스킬 사용 시 성능이 저하되는 현상이 수정됩니다.
  • 일루전 링 : 거대한 머리 장착 후 스킬 사용 시 잔상에 얼굴이 보이지 않는 현상이 수정됩니다.

보이드 블리츠 VI

  • 일루전 링 : 거대한 몸 장착 후 스킬 사용 시 성능이 저하되는 현상이 수정됩니다.
  • 일루전 링 : 거대한 머리 장착 후 스킬 사용 시 잔상에 얼굴이 보이지 않는 현상이 수정됩니다.

레조네이트 VI 본섭 변경

  • 범위 내 대상이 없을 경우 유지 시간이 25% 증가됩니다.

보이드 어웨이크

  • 1타 데미지가 마스터 레벨 기준 4060%에서 4100%로 증가됩니다.
  • 2타 데미지가 마스터 레벨 기준 4330%에서 4505%로 증가됩니다.

헥스 : 듄 버스트

  • 참격 데미지가 마스터 레벨 기준 237%에서 576%로 증가됩니다.
  • 모래 폭발 데미지가 마스터 레벨 기준 426%에서 863%로 증가됩니다.

솔 헤카테

  • 솔 에르다 입자의 데미지가 마스터 레벨 기준 1261%에서 961%로 감소됩니다.
