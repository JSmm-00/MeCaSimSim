# 메이플스토리 스킬 변경 사항 정리 (2026.09.10 테스트월드)

넥슨 [테스트월드 공지](https://maplestory.nexon.com/testworld/news/all/198)의 스킬 수정 사항을 직업별로 정리한 정적 사이트입니다. (9월 11일 오후 1시 55분 수정분까지 반영)

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 첫 화면. 직업 목록, 공지 수정 반영 목록 |
| `common.html` | 전 직업 공통 변경 사항 |
| `hero.html`, `paladin.html` … | 직업별 페이지 (48개) |
| `style.css` | 글꼴·색·여백 등 디자인 |

이미지는 각 HTML 파일 안에 들어 있어서, 이미지 폴더를 따로 올릴 필요가 없습니다.

## 글 고치는 방법

1. GitHub에서 고칠 파일을 클릭해요. 예: `hero.html`
2. 오른쪽 위 **연필(Edit this file)** 아이콘을 눌러요.
3. 화면 위쪽이 실제 글 내용이에요. 원하는 곳을 고쳐요.
4. 오른쪽 위 **Commit changes...** 를 누르면 1~2분 뒤 사이트에 반영돼요.

### 고쳐도 되는 곳

```html
<h3>워리어 리프</h3>                       ← 스킬 이름
<ul class="desc">
<li>전방으로 사용 시 … 변경됩니다.</li>      ← 변경 내용 한 줄
<li>전방으로 1회 점프 후 …</li>             ← 줄을 지우거나 새로 넣어도 됩니다
</ul>
```

- 줄 하나를 지우려면 `<li>`부터 `</li>`까지 통째로 지워요.
- 줄을 새로 넣으려면 `<li>내용</li>` 을 한 줄 추가해요.
- 숫자를 굵게 보이려면 `<b>180%</b>` 처럼 감싸면 돼요.
- 스킬 하나를 통째로 지우려면 `<article ...>` 부터 `</article>` 까지 지워요.

### 건드리면 안 되는 곳

- 파일 **맨 아래** `<script id="imgdata">` 로 시작하는 아주 긴 줄 — 툴팁 이미지 데이터예요.
- `<img data-img="3" ...>` 안의 숫자 — 몇 번째 이미지인지 가리키는 번호예요.
- 파일 맨 위 `<head>` 부분.

### 스킬 하나를 새로 추가하고 싶다면

이미지 없이 글만 넣는 형태예요. 원하는 위치에 붙여넣고 내용만 바꾸면 돼요.

```html
<article class="skill">
<h3>스킬 이름</h3>
<ul class="desc">
<li>바뀌는 내용을 여기에 적어요.</li>
</ul>
</article>
```

## 디자인 바꾸기

`style.css` 맨 위의 색상 값만 바꿔도 분위기가 달라져요.

```css
--accent: #cf5b0c;   /* 강조색 (밝은 화면) */
--bg: #f6f4f0;       /* 배경색 */
```

`@media (prefers-color-scheme: dark)` 안쪽은 어두운 화면일 때 쓰는 색이에요.

## 참고

- 툴팁 이미지는 왼쪽이 변경 전, 오른쪽이 바뀐 내용이에요. 삭제된 스킬 자리를 다른 스킬이 물려받은 경우에는 한쪽만 잘라서 보여줘요.
- 공지 원문이 또 수정되면 이 파일들을 다시 만들어야 해요. 그때 직접 고친 내용은 덮어써지니, 고친 부분은 따로 적어두시는 게 좋아요.
