히어로즈 오쓰

  • 영웅 직업군 파티원의 데미지를 증가시키는 기능이 삭제됩니다.

메르세데스

스피릿 점프 본섭 변경

  • 스킬 설명이 변경됩니다.
  • 전방으로 사용 시 키다운 스킬을 제외한 다른 스킬 사용 중 사용할 수 있게 변경됩니다.
  • 전방으로 점프 후 위 방향으로 점프할 수 있게 변경됩니다.
  • 위 방향으로 점프한 후 전방으로 점프할 수 있게 변경됩니다.

차지 드라이브

  • 스킬 설명이 변경됩니다.

리프 토네이도 본섭 변경

  • 베리안 서지 : 글로리 3타와 연계할 수 있게 변경됩니다.

유니콘 스파이크

  • 적에게 추가 피해를 받는 디버프를 적용하는 기능이 삭제됩니다.

워터실드

  • 액션 딜레이가 약 33% 감소됩니다.
  • 액션 딜레이가 공격 속도의 영향을 받도록 변경됩니다.

엘리멘탈 나이트 본섭 추가

  • 보스 대기맵 입장 시 정령을 최대로 소환하도록 변경됩니다.

이그니스 로어

  • 연계 스킬 사용 시 최종 데미지와 공격 속도가 증가하는 기능이 삭제됩니다.
  • 최종 데미지가 마스터 레벨 기준 17%에서 37%로 증가됩니다.
  • 공격 속도가 영구적으로 증가하는 기능이 추가됩니다.
  • 데미지가 영구적으로 증가하는 기능이 추가됩니다.

이슈타르의 링 본섭 변경

  • 공격 적중 시 이그니스 로어 지속 시간이 증가하는 기능이 삭제됩니다.
  • 화살의 데미지가 마스터 레벨 기준 316%에서 490%로 증가됩니다.
  • 키다운 중 더블 점프 발동 시 스킬이 종료되고 더블 점프되도록 변경됩니다.

레전드리 스피어

  • 적에게 몬스터 방어율을 감소시키는 디버프를 적용하는 기능이 삭제됩니다.

라이트닝 엣지 본섭 변경

  • 스킬 설명이 변경됩니다.
  • 스킬 아이콘 및 스킬 이펙트가 변경됩니다.
  • 스킬 효과음이 변경됩니다.
  • 시전 동작이 삭제됩니다.
  • 연속 사용 가능한 딜레이가 약 6% 감소됩니다.
  • 키다운 스킬을 제외한 다른 스킬 사용 중 사용할 수 있게 변경됩니다.
  • 공격 기능이 삭제됩니다.
  • 이동 거리가 변경됩니다.
  • 공격력이 영구적으로 증가하는 기능이 추가됩니다.
  • 스킬 매크로에 등록할 수 없게 변경됩니다.

롤링 문썰트 본섭 추가

  • 스킬 설명이 변경됩니다.

스피릿 이스케이프 본섭 변경

  • 공격 스킬을 사용하지 않아도 공중에서 사용할 수 있게 변경됩니다.

디펜스 브레이크

  • 방어율 무시 증가량이 마스터 레벨 기준 25%에서 67%로 증가됩니다.

레전드리 스피어-리듀스 아머 본섭 변경

  • 레전드리 스피어-엑스트라 타겟 스킬로 변경됩니다.

엘리멘탈 고스트 본섭 변경

  • 스킬 설명이 변경됩니다.
  • 지속 시간이 마스터 레벨 기준 50초에서 30초로 감소됩니다.
  • 정령의 기운이 항상 등장하도록 변경됩니다.
  • 정령의 기운의 최종 데미지 반영률이 마스터 레벨 기준 45%에서 50%로 증가됩니다.
  • 정령의 기운의 이슈타르의 링과 이르칼라의 숨결 최종 데미지 반영률이 마스터 레벨 기준 22%에서 16%로 감소됩니다.
  • 에우렐의 형상의 데미지가 마스터 레벨 기준 900%에서 1366%로 증가됩니다.
  • 에픽 던전 : 악몽선경의 2 스테이지에서 근두운 탑승 해제 시 잔상이 발생하지 않는 현상이 수정됩니다.

이르칼라의 숨결 본섭 변경

  • 공격 적중 시 이그니스 로어 지속 시간이 증가하는 기능이 삭제됩니다.
  • 키다운 중 점프할 수 있게 변경됩니다.

로얄 나이츠

  • 스킬 설명이 변경됩니다.

이슈타르의 링 VI 본섭 변경

  • 공격 적중 시 이그니스 로어 지속 시간이 증가하는 기능이 삭제됩니다.
  • 화살의 데미지가 마스터 레벨 기준 525%에서 815%로 증가됩니다.
  • 키다운 중 더블 점프 발동 시 스킬이 종료되고 더블 점프되도록 변경됩니다.

리프 토네이도 VI 본섭 변경

  • 베리안 서지 : 글로리 3타와 연계할 수 있게 변경됩니다.
  • 베리안 서지 : 글로리 1타의 데미지 증가 효과가 마스터 레벨 기준 300%p에서 330%p로 증가됩니다.

리프 토네이도 VI : 스피릿 인챈트 본섭 변경

  • 베리안 서지 : 글로리 3타와 연계할 수 있게 변경됩니다.

레전드리 스피어 VI

  • 적에게 몬스터 방어율을 감소시키는 디버프를 적용하는 기능이 삭제됩니다.

유니콘 스파이크 VI

  • 적에게 추가 피해를 받는 디버프를 적용하는 기능이 삭제됩니다.

거스트 다이브 VI 본섭 변경

  • 베리안 서지 : 글로리 2타의 데미지 증가 효과가 마스터 레벨 기준 1140%p에서 1230%p로 증가됩니다.
  • 베리안 서지 : 글로리 3타의 데미지 증가 효과가 마스터 레벨 기준 360%p에서 390%p로 증가됩니다.

스트라이크 듀얼샷 VI 본섭 변경

  • 이슈타르의 링 VI의 데미지 증가 효과가 마스터 레벨 기준 20%p에서 32%p로 증가됩니다.

엘리멘탈 나이트 VI 본섭 추가

  • 보스 대기맵 입장 시 정령을 최대로 소환하도록 변경됩니다.

언페이딩 글로리 본섭 변경

  • 엘리멘탈 고스트 지속 중 사용 시 엘리멘탈 고스트의 지속 시간을 증가시키는 기능이 추가됩니다.
  • 파동의 데미지가 마스터 레벨 기준 707%에서 920%로 증가됩니다.
  • 충돌의 데미지가 마스터 레벨 기준 760%에서 988%로 증가됩니다.
  • 정령왕의 형상의 공격 데미지가 마스터 레벨 기준 2700%에서 2045%로 감소됩니다.
  • 강화 공격의 데미지가 마스터 레벨 기준 1800%에서 1370%로 감소됩니다.

엘리멘탈 스피릿

  • 화살 세례의 데미지가 마스터 레벨 기준 6158%에서 5053%로 감소됩니다.

베리안 서지

  • 적에게 추가 피해를 받는 디버프를 적용하는 기능이 삭제됩니다.
  • 베리안 서지 : 글로리 1타의 데미지가 마스터 레벨 기준 790%에서 959%로 증가됩니다.
  • 베리안 서지 : 글로리 2타의 적에게 추가 피해를 받는 디버프 효과를 적용하는 기능이 삭제됩니다.
  • 베리안 서지 : 글로리 2타의 데미지가 마스터 레벨 기준 1450%에서 1809%로 증가됩니다.
  • 베리안 서지 : 글로리 3타의 데미지가 마스터 레벨 기준 667%에서 824%로 증가됩니다.

엘리멘탈 고스트 강화

  • 정령의 기운의 최종 데미지 반영률이 마스터 레벨 기준 60%에서 70%로 증가됩니다.
  • 정령의 기운의 이슈타르의 링과 이르칼라의 숨결 최종 데미지 반영률이 마스터 레벨 기준 30%에서 22%로 감소됩니다.

솔 헤카테 본섭 추가

  • 솔 에르다 입자의 데미지가 마스터 레벨 기준 775%에서 831%로 증가됩니다.

V 코어 변경점

  • 라이트닝 엣지 강화 코어가 삭제됩니다.
  • 라이트닝 엣지/스피드 듀얼샷/크로스 피어싱 강화 코어가 스피드 듀얼샷/크로스 피어싱 강화 코어로 변경됩니다.
